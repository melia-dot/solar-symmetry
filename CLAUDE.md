# Solar Symmetry

## Versioning

Every time you change app code, bump the version in `src/version.js` using this rule:

- **Patch** number for fixes (1.4.2 → 1.4.3)
- **Minor** number for new features (1.4.2 → 1.5.0)

Mention the new version in the commit message.

`src/version.js` is the only place the version is defined. Don't add it anywhere else.
Also add a short entry to the Version History in `VERSION.md`.
