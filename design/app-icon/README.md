# App icon: "Warm water" (chosen 2026-11-20)

Night sky with fading stars giving way to a sunrise over warm, glowing water.
Chosen for people who dread winter darkness: mostly warm and soft, no harsh black,
the sun close and glowing. Night at the top says "it's been dark"; everything below
says "and now the light is coming".

- `app-icon.svg`: master artwork (1024×1024)
- `app-icon-1024.png`: App Store / source icon, RGB, no transparency
- `splash.svg` / `splash-2732.png`: launch screen, same scene, full-bleed (centre-cropped on phones)

For Capacitor: use these as the sources for `@capacitor/assets` (icon + splash),
replacing the indigo/white-sun icon from Phase 1. The web `icon.svg` is not used
any more (web version retired).
